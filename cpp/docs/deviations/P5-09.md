Ported M5a subset: AtreianPassportService (constructor with the daily cron job, isAtreianPassportDisabled x2, findLastRewardTime,
calculatePassportExpireDate, onLogin and its helpers; takeReward stays unported), BrokerService (constructor, load, race maps, putToSettled,

`model/craft/ProfessionInfo.h`, `model/craft/CraftQuestsLists.{h,cpp}` (MasterQuestsList/ExpertQuestsList getQuestIds), `services/mail/AuctionResultInfo.h`.
Tests: `tests/economy`.

| Area | Java | C++ | Reason |
|---|---|---|---|
| `AtreianPassportService.calculatePassportExpireDate` | `toLocalDate().atTime(LocalTime.MAX).plusDays(14)` (nanosecond 23:59:59.999999999) | 23:59:59.999 of that day plus 14 days | LocalDateTime is millisecond `local_time` (hub-headers.md §6). `isAfter` of a millisecond time gives the same result for both limits, so the behaviour is unchanged. Tests: `AtreianPassportServiceTest.*` (boundary days relative to today) |
| `BrokerService` constructor | `initBrokerService()` first, then `saveManager = new BrokerPeriodicTaskManager(...)` | `saveManager` is a `const Ref` member: its initializer runs `initBrokerService()` first through a comma expression | Keeps Java's log order ("Loading broker..." before "BrokerPeriodicTaskManager initialized."). The four broker maps it fills are declared, and so constructed, before `saveManager`; `playerBrokerCache` is declared after it and is therefore **not** constructed while `initBrokerService()` runs, so that method must not use it (a comment on the member states the invariant). Java runs every field initializer before the constructor body |
| `BrokerService.getFilteredItems` | Returns the live (possibly null) cache list | Returns a snapshot of the cache list (frozen header: `std::vector`); a null list throws `NullPointerException` at once | Java's callers dereference the list immediately |
| `BrokerService.getPlayerCache` | get-then-put on the ConcurrentHashMap | Same, marked `// java-race` | Two concurrent first calls for one player may each create a cache object; kept as in Java |
| `VeteranRewardService` static initializer | Fills `rewards`/`randomRewards` at class initialization | Fills them in the private constructor (run by the first `getInstance()`) | No RefCounted objects at static initialization (hub-headers.md §11.1); `getInstance()` is the only entry, so the lists are filled before any use. The 262 month entries and 29 random rewards were diffed against the Java source |
| `CraftQuestsLists` | `int[] getQuestIds(...)` returns the enum constant's array | `std::span<const int32_t>` over immutable constexpr arrays | Java never writes the arrays |
| `DropService.closeDropList` | `broadcastPacket(npc, packet, dropNpc::isAllowedToLoot)` | The filter lambda holds a `Ref<DropNpc>` taken before the broadcast | The drop registration may be removed concurrently; the borrow must not outlive a removed entry |
| `PricesService` long casts | `(long) (x / 100D)` saturates, `long * int` wraps | Explicit saturating casts and wrapping multiplication | C++ float-to-integer conversion out of range and signed overflow are undefined (CONVENTIONS.md). Test: `EconomyServicesTest.PricesServiceConfigGettersAndSellReward` |
