## M5b-1, stage 2 (loot-partial lane, m5b-plan.md D5 / O-05, m5b-client-session.md S-1)

The first real-client session against the C++ server (2026-09-22, five kills) logged one ERROR per kill,
`onDie() exception for Npc [...]: ...DropRegistrationService::registerDrop ... is not ported yet`. `NpcController::onDie` reaches `registerDrop`

"AION_UNPORTED reached" line, for this body).
