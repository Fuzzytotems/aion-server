## Wave 5a (stats-skills lane, m5a-plan.md B-01..B-04)

| Area | Java | C++ | Reason |
|---|---|---|---|
| `StatCapUtil.limits` | `EnumMap<StatEnum, StatCapRule>` filled by the static initializer; `CapFunction` and the records `Cap`/`StatCapRule` are private nested types | A `static const std::map` returned by `registerDefaults()`; `CapFunction` is a `std::function`, the records are plain structs; the rules, the duplicate check ("A limit for X is already registered") and the unlimited default are Java's | Filled only at static initialization and never modified (hub-headers.md §11.1: no Monitor during static initialization) |
| `PlayerStatFunctions.FUNCTIONS` | `ArrayList` of the 15 package-private function objects, filled by the static initializer | `static const std::vector<IStatFunction*>` in Java order, objects created once and never freed; `getFunctions()` returns borrowed pointers | Immortal static-initializer objects (StatFunction.h lifetimes: no-op retain/release) |
| `StatFunctionProxy.validate` | `((StatFunction) proxiedFunction).validate(stat, this)`: ClassCastException naming the Java classes | `runtime::ClassCastException("StatFunctionProxy: the proxied function is no StatFunction")` | No Java class names at run time; no caller proxies other function types |
| `StatFunction.validate` | Reads the `conditions` field (static data or set by `withConditions`) | Reads the `withConditions` pointer if set, else the bound `conditions` | Static data owns `conditions`; a shared effect template's Conditions cannot be stored into it (StatFunction.h) |
| `ItemEquipmentListener.addStonesStats` / `removeStoneStats` | `Set<? extends ManaStone>` (the item's TreeSet, may be null) | `const std::vector<Ptr<ManaStone>>&` in the set's iteration order (empty for null) | A snapshot of the item's `RcTreeSet`; the stat functions are added in Java's order |
| `ItemEquipmentListener.addStoneStats` | `stone.getModifiers() == null` returns early | No null check | `ManaStone::getModifiers()` is a never-null list in C++ (ManaStone.h) |
| `StatFunctionProxy` access to `StatFunction.validate(Stat2, IStatFunction)` | Package access to the protected method | `friend class StatFunctionProxy;` added to StatFunction.h (additive, own chunk) | C++ has no package access |
| `CreatureGameStats` owner comparison (`addEffectOnly`, `endEffect`) | `Objects.equals` / `equals` | Identity, and `AionObject::equals` (object id) when both owners are AionObjects | Among the StatOwner implementors only AionObject (Item) overrides `equals`; the result is Java's |

Interim lint waivers: the members of the private record `StatCapUtil::StatCapRule` and its `UNLIMITED` constant carry `// fieldmap:` waivers
(L1/L2). They need `fieldmap.toml` decisions from the integrator: the rule table is immutable static data built by the static initializer, so the
record is a value struct instead of a `Ref<StatCapRule>` of `Ref<CapFunction>`s.

Kept Java races (`// java-race`): the unsynchronized read-modify-write of `AggroInfo.hate`/`damage` (addHate, addDamage, reduceHate beside the hate
reduction task), `CreatureLifeStats.synchronizeWithMaxStats`/`updateCurrentStats` and `PlayerLifeStats.updateCurrentStats` (unsynchronized
check-then-set of the current values), `StatArmorMasteryFunction.updateEquipmentFactor` (a reader may see a partial sum).
