## game-server / system messages (`SM_SYSTEM_MESSAGE`, P4-06)

| Area | Java | C++ | Reason |
|---|---|---|---|
| `Object...` parameter types | Any object, formatted with `toString()` in `writeImpl` (`Boolean` "true", `Short`, `Character`, enums by name, objects by their `toString`) | `toJavaString` overloads for `bool`, `int16_t`, `char16_t`, generated enums (constant name) and objects with `toString()` (also through `Ptr`/`Ref`; a null object is written as a null string, the same bytes as ""); formatted at construction | No `Object` in C++ (S0B-035); `bool` would otherwise print "1" |
| `STR_SKILL_ABYSS_SKILL_IS_FIRED`, `STR_ABYSS_ORDER_RANKER_DIE` | `ChatUtil.l10n`, `Race.getL10n()`, `AbyssRankEnum.getRankL10n(player)` | Stand-ins for those three helpers and the `ChatType` ids in `network/detail/SystemMessageL10n.h` (P4-15), tested against the Java sources; the l10n string is WTF-8 like `ChatUtil::l10n` (header request pre-4) | The companions and `ChatUtil` (P4-05, P5-01) do not exist yet; replace when they land |
