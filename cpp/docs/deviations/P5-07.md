## Wave 5a (player-events lane, m5a-plan.md E1-01)

Ported M5a subset: ItemFactory (newItem x2, calculateCount), WarehouseService.sendWarehouseInfo, StigmaService.onPlayerLogin and
addLinkedStigmaSkills (up to getLinkedStigmaLearnSkill), RepurchaseService (addRepurchaseItems, removeRepurchaseItems, getRepurchaseItems,
canRepurchase), LimitedItemTradeService (start, getLimitedItem, isLimitedTradeNpc, getLimitedTradeNpc), LimitedItem (setBuyCount, getBuyCount,

Tests: `tests/itemsvc`.

| Area | Java | C++ | Reason |
|---|---|---|---|
| `RepurchaseService.getRepurchaseItems` | Returns the live `HashSet` stored in the map (or `Collections.emptySet()`) | Returns a snapshot `std::unordered_set<Ptr<Item>>` (frozen header) | Callers only read it; `repurchaseFromShop` (unported) removes from the stored set itself |
| `WarehouseService.sendWarehouseInfo` | `new SM_WAREHOUSE_INFO(null, ...)` | The empty item vector | The packet header documents null as the empty list (P4-16) |
| `LimitedItemTradeService.start` | `CronService.schedule(limitedItem::setToDefault, salesTime)` | An unpinned `bindTask` holding a `Ref<LimitedItem>` | The job retains the item like Java's method reference |
