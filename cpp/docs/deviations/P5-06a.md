# P5-06a the quest engine: deviations

P5-06 was split into P5-06a (the engine), P5-06b (the handler base) and P5-06c (the XML templates) for M5d (m5d-plan.md D1, item I-01). The
rows of the shared `P5-06.md` from wave 5a and M5b-3 stay there; this file holds the engine lane's rows from M5d on. No part may edit
`P5-06.md` (`chunks.py check-ownership` allows a chunk only its own `docs/deviations/<chunk>.md`), so a lane that closes or changes one of its
rows says so here and the integrator edits the shared row when it merges the lane: E-01's closure of the "`isQuestDrop`, a drop with a
collecting step" row, for example. The rows the plan itself puts into `P5-06.md` (D8's acceptance-row deviation at I-05, D9's XML-only
registry) are the integrator's too.
