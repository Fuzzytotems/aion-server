## Wave 5a (player-events lane, m5a-plan.md E1-02..E1-04)

Ported M5a subset: HDDBanService (addBan, removeBan, loadBan, isBanned), SecurityTokenService.generateToken, MultiClientingService (all modes,
including checkForFactionSwitchCooldownTime and AccountSession), SkillLearnService (onLearnSkill, sendPacket, learnNewSkills, learnTemporarySkill,
autoLearnSkills, learnSkillBook, removeSkill), KiskService (onLogin, onLogout, regKisk, haveKisk), TeleportService (sendObeliskBindPoint,
sendKiskBindPoint), BindPointTeleportService (onLogin, addCooldown, getCooldown, Cooldown.getTimeLeft), PunishmentService (updatePrisonStatus,
schedulePrisonTask), PetService.onPlayerLogin, AbyssRankingCache (constructor, refreshCache, reloadRankings, getPlayerRankListPackets, getPlayers,
getLegions, getRankingListPosition x2), AbyssSkillService.updateSkills, RecallService (hasPendingRequest, accept, cancel, remove), DuelService
(getOpponentId, isDueling x2, registerDuel, removeDuel, removeAndEndTask), LifeStatsRestoreService (the four tasks and their schedules),
PlayerLimitService.scheduleUpdate, AbyssRankUpdateService.scheduleUpdate. Tests: `tests/playersvc`.

| Area | Java | C++ | Reason |
|---|---|---|---|
| `HDDBanService.addBan` with a null ban time | Stores `null` in the map, then throws `NullPointerException` at `banTime.getTime()` | Throws `NullPointerException` before storing | The map holds `Timestamp` values and cannot store null. Java's later `isBanned` of that serial would throw as well |
| `HDDBanService.isBanned` | `containsKey` then `get` on a plain `HashMap` | Same two reads on the synchronized shim; a concurrent `removeBan` between them throws `NullPointerException` (`// java-race`) | Kept as in Java |
| `SecurityTokenService.generateToken` | `SecureRandom.nextBytes`, `Base64.getEncoder()` | `std::random_device` (MSVC: the operating system CSPRNG) and a local RFC 4648 encoder with padding | The game server links no OpenSSL. Test: `PlayerServicesM5aTest.SecurityTokenIsBase64OfSixteenRandomBytes` |
| `AbyssSkillService.updateSkills` | `RankingConfig.XFORM_MIN_RANK != null` | Always true | The C++ config field always holds a rank (P4-01 binding); `getId()` is the ordinal + 1 for both enum types, so ordinals are compared |
| `AbyssSkills` enum data | Package-private enum constructor data | A constexpr-like table local to `AbyssSkillService.cpp` | Only this file uses the enum (the generated `AbyssSkills.h` holds the constants) |
| `AbyssRankingCache.refreshCache` | `Collectors.toMap` throws `IllegalStateException` for a duplicate id | `IllegalStateException("Duplicate key <id>")` | Same exception type; Java's message also names the two values |
| `LifeStatsRestoreService` schedules | `scheduleAtFixedRate(new XTask(lifeStats), ...)` | A closure holding the only `Ref` to the task, scheduled with `Pin(&lifeStats.getOwner())` | The pending Future retains the task and, through the life stats part, the creature, as in Java (plan Q3); the pin adds no retention but makes the task visible to the leak census and the zombie breaker (runtime-architecture.md §5.4), which plan Q8 asserts on. Test: `PlayerServicesM5aTest.TheRestoreTaskRetainsTheLifeStatsOwnerUntilItIsCancelled` |
| `PlayerLimitService.scheduleUpdate`, `AbyssRankUpdateService.scheduleUpdate` | `CronService.schedule(..., CronExpression)` with a null config expression throws inside Quartz | `NullPointerException` before scheduling | The config fields are `const CronExpression*` |

### AION_PARTIAL / unported on purpose

- `AbyssRankUpdateService.performUpdate` and `updateDailyGpLoss`: `AION_PARTIAL` (the cron jobs run at midnight and noon and must not throw; the
  rank update is M5b work).
- `PunishmentService.setIsInPrison` (reached only by a prisoned character) and every other body outside the list above stay `AION_UNPORTED`.
