## Audit 2026-09-23, watch item W-1 (a player's hide)

`DuelService.fixTeamVisibility` (DuelService.java:176-184) is ported. `PlayerController.onHide` calls it at every hide of a player, inside
`HideEffect.startEffect` before the hide's observers are added, so while it was `AION_UNPORTED` a player's 3222 *Stealth* kept its SPEED -40 %,
the HIDE state and the HIDE1 visual state with no end task, no observer and no cancel on damage (docs/deviations/P5-03.md, "Reached next").
**No deviation**: every statement and short-circuit is Java's (`getInstance().getOpponentId`, `World.getPlayer`, `knows && !sees &&
isInSameTeam`, `SM_DELETE`). `getOpponentId` and the `duels` map it reads were already ported (wave 5a). Test:
`PlayerServicesM5aTest.FixTeamVisibilityOfAHiderWhoIsNotDuelingEndsAtTheOpponentLookup`; the five player cases of `BuffEffectsTest` (P5-03)
run the whole hide through it.

**What the case cannot assert.** The dueling arm (the World lookup, the two known-list tests, `isInSameTeam` and the second `SM_DELETE`) has no
unit case: nothing public can register a duel (`registerDuel` is private and its only caller `startDuel`, like `onDuelRequest` and
`confirmDuelWith`, is `AION_UNPORTED`), so no C++ caller reaches the arm either. A case needs either those bodies or a test access to the
`duels` map (a header request: e.g. `friend struct DuelServiceTestAccess;` in `DuelService.h`), not applied here.

**`isInSameTeam` at HEAD.** For a player in no team it reaches no unported body: `getCurrentTeam` answers null (`playerGroup` and
`playerAllianceGroup` empty) and `getCurrentTeamId` 0. For a player in a group or alliance it reaches `GeneralTeam::getTeamId`,
`AION_UNPORTED` at `model/team/GeneralTeam.cpp:80-82` (P5-10; the Java body is `return getObjectId();`, GeneralTeam.java:153-155). No C++
code can put a player into a team yet (nothing outside `Player.cpp` calls `setPlayerGroup` or `setPlayerAllianceGroup`), so it is latent here
and in `Player.canSee`, which calls `isInSameTeam` for every hidden player; it goes live with the first group body of P5-10.
