# P5-05 AI framework: deviations

## Wave 5a (world-engines lane, m5a-plan.md W-01)

| Area | Java | C++ | Reason |
|---|---|---|---|
| `AIEngine.validateScripts`, handler checks | Reflection: "Faulty AI handler: ... missing generic owner type info" / "... missing constructor taking owner" | Not checked at run time: the `AION_AI` marker checks the owner type and the constructor at compile time (HandlerRegistry.h `AIHandlerClass`) | No reflection |
| `AIEngine.validateScripts`, missing template AI names | `String.join(", ", npcAINames)` of a `HashSet` (unspecified order) | The distinct names sorted | Deterministic message |
| `AIEngine.registerAI` | `aiHandlers.putIfAbsent(name, class)`, IllegalArgumentException for a duplicate name | The registry (sorted by name, unique names) stands for the map: an entry is accepted when the registry holds exactly that entry under its name, or none | The compiled handler registry replaces the class map (AIEngine.h) |
| `AbstractAI.onCreatureEvent`, event recursion guard | `throw new StackOverflowError(...)` (an `Error`, not caught by `catch (Exception)`) | `commons::utils::Exception` with the same message | C++ has no Error hierarchy; callers that catch `std::exception` also catch it |
| `AbstractAI.handleCreatureEvent`, `(Player) creature` for DIALOG_START/DIALOG_FINISH | ClassCastException "class <FQN> cannot be cast to class ...Player" | `runtime::ClassCastException` whose message starts with the C++ type name | No Java class names at run time |
| `AbstractAI.setStateIfNot`, DIED to FIGHT with logging | Logs each `StackTraceElement` of a new Throwable | Logs each line of `std::stacktrace::current()` | Stack trace format |
| `AbstractAI.getName` | `@AIName` annotation of the class, "noname" without | The registry entry `newAI` stored (`setRegistryEntry`), "noname" without | No annotations (AbstractAI.h) |
