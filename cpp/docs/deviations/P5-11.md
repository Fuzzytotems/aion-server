### P5 leftovers cp1: HouseRegistry.discard (lane B, 2026-10-18)

The generic helper `discard` (HouseRegistry.java:136-146) and its lambda (:145) are ported statement for statement as the private member
template `HouseRegistry::discard<T>`. The header declares it, and `HouseRegistry.cpp` defines it, because only that file calls it.
`discardObject` and `discardDecor(HouseDecoration, boolean)` call it again as Java does, instead of each writing out a copy. Test:
`StudioHouseTest.DiscardRemovesNewOrDirectEntriesMarksTheRestDeletedAndDropsUseCooldowns`.
