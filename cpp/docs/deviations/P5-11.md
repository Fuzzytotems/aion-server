loadLegionInfo, getLegionMember x4, checkDisband, LegionWhUpdate; onLogin, onLogout and disbandLegion stay unported), LegionDominionService (initLocations,

`model/house/HouseDoorStateInfo.h`. Tests: `tests/legionhouse`.

| Area | Java | C++ | Reason |
|---|---|---|---|
| `House.setPermissionsFromDB` | An unknown door state id stores `null`, then `resetDoorState()` always changes the state | The field cannot hold null: it is set to `CLOSED_EXCEPT_FRIENDS` (never chosen by `resetDoorState`) before `resetDoorState()`, which then always changes it and requests an update | Same observable state and persistent state. Test: `HouseModelTest.PermissionsRoundTripAndInvalidDoorStates` |
| `HousingService.changeOwner` | `house.setSignNotice(null)` | `setSignNotice("")` | `House.signNotice` is a `Field<std::string>` (frozen header); HousesDAO stores the notice as a string, and the house packets write null as an empty string |
| `LegionDominionLocation.getRace` | Returns the template's race, null if absent | Throws `NullPointerException` for a template without race | The return type is `Race` (frozen header); every `legion_dominion_location` of the static data has a race, and Java's callers dereference it |
| `Town.increaseLevel` | `levelUpDate.setTime(now)` mutates the stored Timestamp | Stays `AION_UNPORTED` | `Town::levelUpDate` is `const` in the frozen header. Header request `economy-legion-1` was deferred to wave 5b (nothing on the M5a path levels a town up; towns level up through quests); the agreed form is `runtime::Field<std::optional<commons::database::Timestamp>>` |
| `Town` constructor, a NULL `towns.level_up_date` | Stores the `null` Timestamp; `SM_TOWNS_LIST` then throws `NullPointerException` at `getLevelUpDate().getTime()` | `levelUpDateValue.value_or(Timestamp{})`, so `getLevelUpDate()` is always engaged and `SM_TOWNS_LIST` would write 0 | The frozen member is a non-optional `Timestamp`. Latent only: the column is `NOT NULL` in `sql/aion_gs.sql`. The deferred header request above removes the substitution |
| `Town` constructor | `for (Spawn spawn : getSpawns(id, level))` throws `NullPointerException` when no town spawn map has the town | Throws `NullPointerException` with a message naming the town | Explicit check for the null the Java loop dereferences |
| Housing cron tasks | `AuctionEndTask/AuctionAutoFillTask/MaintenanceTask.getInstance()` construct the task at class initialization | `getInstance()` creates the task on first use as a never-released `Ref` and calls `AbstractCronTask::postConstruct()` (two-phase construction, docs/deviations/P5-14.md) | RefCounted singletons (hub-headers.md §11.2 per-run pattern) |

| `AuctionAutoFillTask.executeTask` | `autoFillAuction(ELYOS)`, `autoFillAuction(ASMODIANS)` when auctions are enabled | `AION_PARTIAL("automatic house auction registration is not ported yet ...")` when enabled | `HousingBidService.auction` is not ported yet |
| `MaintenanceTask.executeTask` | For an overdue house: owner lookup, impoundment (`putHouseToAuction`) and `MailFormatter.sendHouseMaintenanceMail` | The first-week branch (`setNextPay(getNextRun())`, `save()`) is ported; an overdue house reaches `AION_PARTIAL("overdue house maintenance ...")` | Impoundment needs `HousingBidService.auction` and MailFormatter |
