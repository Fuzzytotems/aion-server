## game-server / base (P4-05: utils, model direct classes and enums, model.geometry, audit, cache)

| Area | Java | C++ | Reason |
|---|---|---|---|
| `PacketSendUtility.sendPacket` | `if (player.isOnline()) player.getClientConnection().sendPacket(packet)` loads the connection twice; a logout between the loads throws `NullPointerException` | The connection is loaded once and used if non-null | Obvious race (D6); runtime-architecture.md §8.3 already loads it once |
| `PositionUtil` sin/cos | `Math.sin`/`Math.cos` (HotSpot intrinsics) | C runtime `std::sin`/`std::cos`; `Math.atan2` is the bit-exact `StrictMath` port | The intrinsics are not bit-specified; results may differ in the last bit before the float casts |
| `CompressUtil.decompress` errors | `DataFormatException` with zlib's message for invalid data; `RuntimeException("Bad zip data, size: N")` for truncated data or a preset dictionary | `IllegalArgumentException` with the message of zlib's inflate (same checks in the same order); `IllegalStateException("Bad zip data, size: N")` | No checked exception types; the messages are kept. `compress` is a port of zlib's level 6 deflate and returns Java's bytes (zlib 1.3.1 vectors), because the game server does not link zlib |
| `HTMLCache` cache file | Serialized `HashMap` (`ObjectOutputStream`) | Own format: "AIONHTM1", then UTF-8 key and value with 4-byte little endian lengths; a Java cache file fails to load, is logged and rebuilt (Java's broken-file path) | C++ cannot read Java serialization |
| `HTMLCache` encoding | Files decoded with `HTMLConfig.HTML_ENCODING` | Files read as UTF-8 | No charset library; the configured default is UTF-8 |
| `CAPTCHAUtil.createImage` | `java.awt` renders the word with bold 25 pt Verdana into a 160x80 image | Unported (`AION_UNPORTED`), so `createCAPTCHA` throws; `getRandomWord` and `DDSConverter` are ported | No text rasterizer; needs a decision (font, bitmap glyphs) before the CAPTCHA feature can work |
| `Polygon2D` awt methods | `Polygon2D(Polygon)`, `getPolygon()`, `getPolyline2D()` (class `Polyline2D`), `addPoint(Point2D)`, `contains(Point)`, `contains(Point2D)`, `getBounds()`, `getPathIterator` | Not declared; `Rectangle2D` and the `GeneralPath` state are small value structs (`Polygon2D::Rectangle2D`, `Polygon2D::Path2D`) with Java 25's crossing and bounds rules | No java.awt types; none of them has a caller |
| `RectangleArea(ZoneName, int, Point, Point, Point, Point, int, int)` | Bounding box of four `java.awt.Point` via `Rectangle.add` | Not declared | No java.awt types; no caller |
| `XmlUtil`, `JAXBUtil`, `StringSchemaOutputResolver`, `XmlValidationHandler` | JAXB unmarshalling, DOM documents, XSD schemas and validation events | Only `XmlUtil.listFiles` (one overload taking `std::filesystem::path`); the rest has no C++ counterpart | The static data runtime (pugixml binders with strict binding, static-data.md) replaces JAXB and XSD validation. The Java callers outside static data (SpawnsData XML write-back with schema validation, the rift, siege and world raid schedule loaders, InGameShopProperty, DatabaseCleaningService) need binder entry points of their own owners (open issue) |
| `ChatUtil` link detection in `split` | `Character.isLowerCase` for every Unicode lowercase letter | Lowercase letters that commons `StringUtils` maps (ASCII, Latin-1, Latin Extended-A, Greek, Cyrillic) | No Unicode property tables; links start with ASCII names |
| `ChatUtil.l10n` | Two UTF-16 code units, possibly a lone surrogate, written to the packet unchanged by `writeS`; null for id 0 | The same units as WTF-8 (commons `StringUtils::toWtf8`, a lone surrogate as its own 3-byte sequence), which the server packet `writeS` helpers decode back to the same units (`wtf8ToUtf16`), so the wire bytes equal Java's; `split` decodes and encodes WTF-8 too. Id 0 returns "" instead of null. Such a string is not valid UTF-8: text that leaves the packet path (database, logs) would carry the 3-byte sequences | UTF-8 strings cannot hold lone surrogates (header request pre-4, docs/porting/header-requests.md). "" is the `L10n::getL10n` convention for null |
| `GMService.getOnlineStaffMembers` | Live `values()` view of the staff map | Snapshot `std::vector<Ptr<Player>>` | hub-headers.md §7.1 collection returns |
| `ServerTime` | `ZonedDateTime` with nanoseconds; `parse` accepts every `ISO_ZONED_DATE_TIME` form | `std::chrono::zoned_time` with milliseconds; `parse`/`parseLocal` accept `yyyy-MM-ddTHH:mm[:ss[.fraction]]` with `Z`/`±HH:MM[:SS]` and an optional `[Region/City]`; parse errors are `IllegalArgumentException` | The server and the DAO layer use milliseconds; the accepted forms are those the server's data and commands use |
| `Area.getClosestPoint` | Returns new `Point2D`/`Point3D` objects, null for `SphereArea` | The `Point3D` overloads return a new `Ref<Point3D>` (null for `SphereArea`); the `Point2D` overloads return the point by value as `std::optional<Point2D>` (`std::nullopt` for `SphereArea`); `AbstractArea` subclasses compute closest points with the C++-only `getClosestPoint2D` | `Point2D` is a value type without identity; header requests base-1 and base-2 (docs/porting/header-requests.md) |
| `Chance.selectElement` | `static <T extends Chance> T selectElement(Iterable<T>, boolean)` returning null | Member function template over a container of pointer-like elements; returns a value-initialized element for null | No null references; the elements are `const X*` templates or `Ptr`/`Ref` |
| `AutoBan.punishment` | `protected static`, reachable from the package (`AuditLogger`) | `private static` with `AuditLogger` as friend | C++ has no package access |
| `PlayerActions.setPlayerMode` | `Object obj` cast to `RideInfo` or `InRoll` | `const std::any&` holding `const RideInfo*` or `Ref<InRoll>`; a wrong type throws `std::bad_any_cast` | hub-headers.md §7.4 |
| Enum companions | Methods and constructor data of the Java enums (`ChatType.getId()`, `Race.getRaceByString`, ...) | Free functions in `<Enum>Info.h` (`getId(chatType)`); nullable results are `std::optional`; `TribeClass.isGuard` searches the name on each call instead of a field set by the constructor | Generated enums cannot have members (static-data.md §2.5) |
