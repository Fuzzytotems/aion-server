`aggressive_stonespear`, `stonespear_guardian_stone`), statement for statement. The score is M5h's `LegionDominionScore` with its

| Area | Java | C++ | Reason |
|---|---|---|---|
| `startTime` | `Long`, unboxed in `getTime` and in `checkRank`'s `endTime - startTime` | `std::optional<int64_t>`; an unset value throws `NullPointerException` where Java's unboxing would | a nullable box (hub-headers.md §6) |

| Scheduled lambdas | `ThreadPoolManager.schedule(runnable, delay)` | pinned to the handler (`schedule({this}, ...)`), the stage tasks through `addTask` | the runtime's pinning rule |
