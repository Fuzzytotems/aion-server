# P5-09a drop, rewards and packs: deviations

P5-09 was split into P5-09a (drop, rewards, passport, bonus and faction packs, guide), P5-09b (trade and market) and P5-09c (mail and craft) for
M5c (m5c-plan.md D1, I-01). The rows of the shared `P5-09.md` from waves 5a to M5b-3 stay there (among them M5b-3's drop services); this file
holds P5-09a's rows from M5c on.

## M5c stage 1 (mail lane, m5c-plan.md R-02)

Ported: `StarterKitService.onLevelUp` (StarterKitService.java:63-75), the file's only `AION_UNPORTED`. It is reached only with
`gameserver.custom.starter_kit.enable` (default false, `PlayerController::onLevelChange`). Tests: `tests/economy/P5-09a/StarterKitServiceTest.cpp`
(on the mail lane's `tests/economy/P5-09c/MailTestSupport.h`, found through the executable's include directories; five verbatim item rows of
the level-1 and level-25 kits). Mutation-proven with the mail lane's schemata build: both loop bounds, the missing-level guard, the letter type
and the item count, each mutant killed.

| Area | Java | C++ | Reason |
|---|---|---|---|
| The level loop | `for (int level = fromLevel; level <= toLevel; level++)`: with `toLevel == Integer.MAX_VALUE` the `int` wraps and the loop never ends | the same `int32_t` loop; its increment past `INT32_MAX` would be undefined | The only caller passes character levels (`minNewLevel`, `newLevel`), so neither tree reaches it |
