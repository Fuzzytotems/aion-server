## M5j stage 2 CP4: //dye (2026-10-08, lane A, branch `lane-a/m5j-s2-cp4`)

`//dye` (Dye.java) at parity. Java's reflective `Class.forName("java.awt.Color").getField(colorParam.toUpperCase())` inside
`try { ... } catch (Exception e)` is `utils::JavaColor::byName`, whose std::nullopt takes the catch's hex code path; `colorParam.length()` is
the UTF-16 length. Item.setItemColor keeps the low 24 bits (Color.RED is stored as 0xFF0000). Tests: `ItemCommandsTest.DyeColorsTheVisibleEquipment`
(C1.md, CP4: nothing visible, nothing dyeable, a color name, a paint item, `#` and `0X` hex codes, an invalid color, the removal).
