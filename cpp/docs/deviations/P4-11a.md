## game-server / game objects (P4-11a, `model/gameobjects` without `player`, `model/assemblednpc`, `model/flyring`, `model/road`)

| Area | Java | C++ | Reason |
|---|---|---|---|
| `Creature.setSkillCoolDown` first call | `if (skillCoolDowns == null) skillCoolDowns = new ConcurrentHashMap<>()` unguarded: two first calls on different threads can each create a map, and the cooldown written into the replaced map is lost | The new map is published with a compare-and-set; a caller that loses the race writes into the winner's map | Java race (D6); test `CreatureBodiesTest.ConcurrentFirstCooldownsAreNotLost` |
| `Item.getItemStones`, `getFusionStones`, `getCurrentModifiers` first calls | Same unguarded lazy creation: concurrent first calls can return different collections and lose added stones or modifiers | Published with a compare-and-set, every caller gets the same collection | Java race (D6); test `GameObjectsModelTest.LazilyCreatedItemCollectionsArePublishedOnce` |
| `Item` DAO constructor persistent state | `null` until `InventoryDAO` sets `UPDATED` | `NOACTION`: every `setPersistentState` transition and the `NEW`/`CHANGED`/`DELETED` predicates treat it like `null`; only a `getPersistentState()` read before the DAO's store differs | `Field<PersistentState>` has no null |
| `Item.toString` mana stone sets | `ManaStone@<identity hash>` per element | `com.aionemu.gameserver.model.items.ManaStone@<low 32 bits of the address>` | No identity hash in C++; debug text only |
| `Creature.canUseSkillInMove` | Looks the casting skill's template up in `DataManager.SKILL_DATA` | Reads the casting skill's own template (the same object: every Skill is created from `SKILL_DATA`) | Written before `SkillData::getSkillTemplate` existed (header request shells-1); no behaviour difference while a skill is casting, and the objects tests need no published `SKILL_DATA` |
| `Npc.getRating`, `getRank`, `getGroupDrop` for a template without the attribute | Return `null` | Throw `NullPointerException` | The frozen `Npc` accessors return the enum (no null); every `npc_template` of the static data has `rating`, `rank` and `group_drop` |
| `GroupRecruitment.getRace` for an object that is neither a Player nor a team | Returns `null` | Throws `NullPointerException` | The frozen accessor returns `Race`; `FindGroupService` registers only players and teams |
| `Letter` and `BrokerItem` (DAO constructor) with a null `settleTime`/`timeStamp` | Keep `null` | Keep the epoch | The frozen members are non-optional `Timestamp`s; the `mail.recieved_time` and `broker.settle_time` columns are `NOT NULL` and the services always pass the current time |
| `Kisk` of an npc template without `kisk_stats` | `new KiskStatsTemplate()` per Kisk | One immortal default `KiskStatsTemplate` shared by these Kisks | Keeps `const KiskStatsTemplate*` a static data pointer; the template is immutable, so the values are the same |
| `StaticDoor.states` / `getStates()` | `EnumSet<StaticDoorState>`, returned live | `TreeSet<StaticDoorState>` shim (ordinal order like EnumSet); `getStates()` returns a `std::set` snapshot | No EnumSet shim; the only caller formats the states |
| `Homing`, `Servant`, `SummonedHouseNpc` master name | The constructors store `""`, which `SummonedObject.getMasterName` returns because it is not null | C++-only `getMasterName()` overrides return the stored name or `""` | `Npc.masterName` is a `Field<std::string>` in which `""` reads as null; without the overrides the creator's name would be shown. `Trap` has the same override (header request objects-1) |
| `Servant.getNpcObjectType` before `setNpcObjectType` | `null` | `NORMAL` | The member keeps the fieldmap spelling `Field<NpcObjectType>`; `VisibleObjectSpawner` sets the type right after creation |
| `AssembledNpc` parts | Stores the caller's list | Copies the parts into its `ArrayList` shim, in order | The frozen member is the shim; `BalaurAssaultService` builds the list for this object only |
| `Item.toString` item creator | Concatenates the raw field: `null` for items made by the simple constructors, `""` only if an empty creator was stored | `null` whenever the creator is empty | `Npc.masterName`-style `Field<std::string>`, in which `""` reads as null; debug text only |
