# Deviations of chunk P4-09 (static data holders)

To be merged into [../DEVIATIONS.md](../DEVIATIONS.md) by the integrator. The class and function comments name each one.

## game server / static data holders

| Area | Java | C++ | Reason |
|---|---|---|---|
| Holder index maps (`SkillData`, `ItemSetData`, `WorldMapsData`, `NpcData`; since wave 3a-2 also `MaterialData`, `ItemData`, `HouseBuildingData`, `ItemRandomBonusData`, `TemperingData`, `RecipeData`) | `afterUnmarshal` builds `HashMap`/`LinkedHashMap` indexes and sets the bound list to null | The indexes are `std::unordered_map`/`std::map` of template pointers into the bound storage, which stays (static-data.md §2.6, as `QuestsData`) | Stable template addresses without copying the templates |
| `SkillData.getSkillTemplates` order | `HashMap<Integer, SkillTemplate>.values()` | The same order, computed once by `afterUnmarshal` from a model of `HashMap.putVal`/`resize`/`treeifyBin` (buckets in index order, each bucket in put order); a bucket that Java turns into a red-black tree (8 or more keys in one bucket of a table of 64 or more buckets) keeps put order instead of the tree's link order | The real skill data never has more than 2 keys in a bucket (13,570 templates, table of 32,768); tests `SkillDataTest.SkillTemplatesInJavaHashMapOrder`, `TreeifyBinResizesSmallTables` |
| `HouseBuildingData.afterUnmarshal` duplicate id | Throws `IllegalArgumentException("Duplicate building ID " + id)`; JAXB aborts the load | `LoadContext::fail` throws `StaticDataException` with the Java message and the file location | The loader's error type (as the P4-07a/b hooks); startup fails the same way. Test `HouseBuildingDataTest.BuildingsByIdAndDuplicates` |
| `ItemRandomBonusData.bonusData` | `EnumMap` with an empty `HashMap` for every `StatBonusType`, filled by `afterUnmarshal` | A `std::map` keyed by the bonus types that have sets; a missing key reads as Java's empty map | Not observable: `getTemplate` returns null for an unknown set either way |
